# LAMTORRO Business Radar

Aplikasi prospek bisnis dengan fokus Bali. Buka `index.html` di browser atau jalankan `node server.mjs` dan buka http://127.0.0.1:4173.

Pilih cakupan dan industri. Gunakan data contoh untuk menguji alur secara lokal. Pencarian langsung memakai OpenStreetMap dan memerlukan internet. Tautan situs dan kontak perlu diverifikasi sebelum digunakan.

Prospek dan catatan disimpan di browser. Demo HTML dapat diunduh. Kode QR memakai tautan ulasan resmi dari bisnis. Gunakan tautan yang sama untuk menulis tag NFC dan undang semua pelanggan memberi ulasan jujur.
